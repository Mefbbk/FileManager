# File Manager (Android)

Файловый менеджер на Kotlin + Jetpack Compose (Material 3).

## Возможности
- Просмотр папок внутренней памяти (папки сверху, размер и дата изменения).
- Встроенный просмотр PDF на системном `PdfRenderer` — без сторонних библиотек, страницы рендерятся лениво при прокрутке, счётчик «страница / всего».
- Встроенный просмотр фото: листание по папке, масштаб щипком и двойным тапом, учёт EXIF-поворота, HEIC на Android 9+.
- Меню «⋮» у каждого файла: «Відкрити в іншому додатку» и «Поділитися»; те же кнопки в просмотре PDF и фото. В списке давно не используемых можно поделиться сразу несколькими выбранными файлами.
- Остальные файлы открываются в подходящем установленном приложении (через `FileProvider`).
- Интерфейс на украинском.
- **Давно не используемые файлы**: рекурсивный поиск по всей памяти с порогом 1 / 3 / 6 / 12 месяцев, сортировка от самых старых, общий размер, выбор и удаление с подтверждением.

## Как определяется «не использовался»
Берётся более поздняя из двух дат: последнего изменения и последнего доступа (`lastAccessTime`).
На многих телефонах память смонтирована с `noatime`/`relatime`, поэтому дата доступа может не
обновляться при просмотре — файл считается неиспользуемым, только если обе даты старые.
Скрытые папки (`.xxx`) и системная папка `Android/` пропускаются.

## Запуск
1. Android Studio → **File → Open** → выбрать папку `FileManager`.
2. Дождаться Gradle Sync (AGP 8.7.3, Kotlin 2.0.21, Gradle 8.9, JDK 17).
   Если Studio предложит обновить AGP/Gradle — можно соглашаться.
3. Запустить на устройстве/эмуляторе (minSdk 26 = Android 8.0).
4. На Android 11+ при первом запуске нажать «Разрешить доступ» и включить
   «Доступ ко всем файлам» для приложения.

> `MANAGE_EXTERNAL_STORAGE` подходит для личного использования и портфолио;
> для публикации в Google Play нужно отдельное обоснование в Play Console.

## Структура
```
app/src/main/java/com/anatoliy/filemanager/
├── MainActivity.kt          # тема, проверка разрешений, стек экранов
├── FileRepository.kt        # список папки, поиск неиспользуемых, удаление
├── PdfDocument.kt           # обёртка над PdfRenderer (отдельный поток)
├── StoragePermission.kt     # доступ к хранилищу для Android 8–10 и 11+
├── FileUtils.kt             # форматирование, открытие во внешнем приложении
└── ui/
    ├── FileBrowserScreen.kt
    ├── PdfViewerScreen.kt
    ├── UnusedFilesScreen.kt
    ├── UnusedFilesViewModel.kt
    ├── PermissionScreen.kt
    └── FileRow.kt
```

## Идеи для развития
- Масштабирование PDF жестом (pinch-to-zoom).
- Открытие PDF из других приложений (intent-filter `application/pdf`).
- Поиск по имени, сортировка, копирование/перемещение.
- Фильтр «большие и старые» (например, > 50 МБ).
