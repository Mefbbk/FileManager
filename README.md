# File Manager (Android)

Файловий менеджер для Android на Kotlin + Jetpack Compose (Material 3). Інтерфейс українською. Окрім AndroidX і системних API використовує лише Google ML Kit і PdfBox-Android (для перекладача PDF).

## Можливості

### Перегляд і навігація
- Внутрішня пам'ять, **SD-карта і USB-флешка**; у боковому меню — смужка зайнятого місця для кожного сховища.
- **Шлях угорі** (`Пам'ять пристрою › Download › Books`) — будь-яку частину можна натиснути.
- **Швидкі папки**: Завантаження, Камера, Знімки екрана, Документи, Музика, Фільми, Telegram.
- **Фільтр за типом** угорі: Фото, Відео, Музика, Документи, FB2, Архіви, APK, Інше — з лічильниками.
- **Сортування** за назвою, датою, розміром або типом, у будь-якому напрямку (запам'ятовується).
- **Список або сітка**; для фото й відео — галерея мініатюр.
- **Мініатюри**: фото, кадр із відео, обкладинки музики та книжок FB2, перша сторінка PDF, іконки додатків в `.apk`.
- **Пошук за назвою** у поточній папці та всіх підпапках, з результатами в міру сканування.
- Показ прихованих файлів, оновлення свайпом донизу, збереження позиції прокрутки.

### Дії з файлами
- **Вибір галочками** (довге натискання), «вибрати всі».
- **Копіювання і переміщення** через панель «Вставити сюди»; однакові назви отримують суфікс ` (1)`.
- **Перейменування** з перевіркою назви, **нова папка**, **видалення** з підтвердженням.
- **ZIP**: розпакування (у т. ч. кириличні назви з Windows-архівів) і стиснення вибраного.
- **Властивості**: шлях, точний розмір, вміст папки, роздільна здатність фото, тривалість і теги відео/музики.
- «Поділитися» і «Відкрити в іншому додатку» для будь-якого файлу; встановлення `.apk` натисканням.

### Вбудовані переглядачі
- **PDF** на системному `PdfRenderer`, масштаб щипком і подвійним тапом.
- **Перекладач PDF** — безкоштовний і офлайн (Google ML Kit): текст сторінки береться з PDF або розпізнається зі скану, мова визначається автоматично, переклад українською, англійською, німецькою, польською та ін. Мовна модель (~30 МБ) завантажується один раз, далі текст не залишає телефон.
- **Фото**: листання по папці, масштаб щипком і подвійним тапом, EXIF-поворот, HEIC.
- **Текст** (`.txt`, `.log`, `.json`, `.xml`, `.md`, `.csv` …): UTF-8 або windows-1251, зміна розміру шрифту.
- Додаток з'являється у «Відкрити за допомогою» для PDF, фото і `.txt` з інших додатків.

### Інструменти
- **Аналіз пам'яті**: що займає місце за типами, найбільші папки, 100 найбільших файлів.
- **Пошук дублікатів** за вмістом (розмір → хеш початку й кінця → повний MD5), автовибір усіх копій, крім найстарішої.
- **Давно не використовувані файли**: 1 / 3 / 6 / 12 місяців, від найстаріших.

## Збірка
Потрібні JDK 17 і Android SDK (compileSdk 35).

```
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Або відкрити папку в Android Studio (AGP 8.7.3, Kotlin 2.0.21, Gradle 8.9).

minSdk 26 (Android 8.0). На Android 11+ під час першого запуску треба дозволити «Доступ до всіх файлів».

> `MANAGE_EXTERNAL_STORAGE` і `REQUEST_INSTALL_PACKAGES` підходять для особистого використання; для Google Play потрібне окреме обґрунтування.

```
├── MainActivity.kt        стек екранів, налаштування, файли з інших додатків
├── FileRepository.kt      список, пошук, копіювання/переміщення, перейменування, видалення
├── FileCategory.kt        типи файлів для фільтра
├── Sorting.kt             сортування
├── Storages.kt            внутрішня пам'ять, SD-карта, USB
├── StorageScan.kt         аналіз пам'яті і пошук дублікатів
├── Zip.kt                 розпакування і стиснення
├── Fb2.kt                 обкладинки FB2
├── PdfDocument.kt         обгортка над PdfRenderer
├── PdfTranslation.kt      текст PDF, OCR, визначення мови, переклад
├── StoragePermission.kt   доступ до сховища
├── FileUtils.kt           форматування, відкриття, «поділитися», встановлення APK
└── ui/
    ├── FileBrowserScreen.kt, BrowserExtras.kt, BrowserParts.kt, AppDrawer.kt, FileRow.kt
    ├── Thumbnails.kt, PropertiesDialog.kt
    ├── ImageViewerScreen.kt, PdfViewerScreen.kt, PdfTranslateScreen.kt, TextViewerScreen.kt
    ├── AnalysisScreen.kt, DuplicatesScreen.kt
    └── UnusedFilesScreen.kt, UnusedFilesViewModel.kt, PermissionScreen.kt
```
